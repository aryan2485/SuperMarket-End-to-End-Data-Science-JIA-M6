# SuperMarket End-to-End Data Science Project

## Overview

This project is an end-to-end Data Science project based on supermarket
transaction data.

The project covers exploratory data analysis, visualization,
data preprocessing, Machine Learning, prediction, and model evaluation.

## Objectives

- Analyze supermarket sales data
- Identify meaningful patterns
- Create data visualizations
- Build a Machine Learning model
- Predict supermarket sales
- Evaluate model performance
- Generate business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Machine Learning

### Model

Random Forest Regressor

### Target

Sales

### Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Workflow

1. Data Collection
2. Data Loading
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Feature Preparation
7. Train-Test Split
8. Machine Learning
9. Prediction
10. Model Evaluation
11. Business Insights
12. Conclusion

## Dataset

The project uses supermarket transaction data containing information
about branches, cities, customers, product lines, prices, quantities,
sales, payment methods, ratings, and gross income.
